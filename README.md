# Riolup TCG - Android App

Aplicación móvil desarrollada en Android Studio como parte de la primera entrega del proyecto de la materia.

La aplicación permite visualizar y gestionar un álbum de cartas del Pokémon Trading Card Game, utilizando información obtenida desde la Pokémon TCG API.

## 📱 Descripción

El proyecto consiste en recrear una aplicación móvil para consultar y administrar cartas de Pokémon TCG.

En esta primera entrega se implementó principalmente la interfaz de usuario del álbum y la integración con la API para obtener las cartas de manera dinámica.

Las cartas no se almacenan como imágenes locales, sino que sus imágenes se obtienen desde la API.

## ✨ Funcionalidades

- Visualización del álbum de cartas.
- Carga dinámica de cartas mediante la Pokémon TCG API.
- Visualización de las cartas en una grilla.
- Scroll vertical para visualizar las cartas.
- Contador de cartas del álbum.
- Visualización de información básica de las cartas.
- Interacción con las cartas mediante eventos de click.
- Diseño de la interfaz basado en el prototipo proporcionado para el proyecto.

## 🛠️ Tecnologías utilizadas

- **Java**
- **Android Studio**
- **Android SDK**
- **XML** para el diseño de interfaces.
- **GridLayout**
- **ScrollView**
- **ConstraintLayout**
- **LinearLayout**
- **Glide** para la carga de imágenes.
- **Pokémon TCG API** para obtener la información de las cartas.

## 🌐 Pokémon TCG API

La aplicación utiliza la [Pokémon TCG API](https://pokemontcg.io/).

API base:

```text
https://api.pokemontcg.io/v2
```
